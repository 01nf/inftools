# 🧬 inftools — Infra

**Infra** is an open-source organization focused on building lightweight, modular tools for:

- 🔐 **Security research and testing**
- ⚡ **Automation and system optimization**
- 🧬 **Experimental languages and interpreters**
- 🌐 **Privacy-preserving development**

All tools are self-contained, require no installation, and are designed for educational and research purposes.
